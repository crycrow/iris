# Система управления рисками IT-проектов

Проект «Ирис» создан студентами Финансового университета - Маркушевой В.М. и Сиваковой Т.С.
Информационная система разработана в рамках ВКР по теме «Разработка информационной системы для управления рисками IT-проектов на основе данных об использовании рабочего времени»
